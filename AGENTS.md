# AGENTS.md — Memória e Diretrizes do Projeto

## Visão Geral
- **Nome:** `clone-tab-new-ia`
- **Objetivo:** Implementação do [TabNews](https://tabnews.com.br) para o [curso.dev](https://curso.dev).
- **Idioma:** Português (`pt-BR`) na interface e na comunicação com o usuário.

## Comandos Principais
- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — gera o build de produção
- `npm run start` — inicia o servidor em modo produção

## Convenções e Manutenção
- Seguir a arquitetura do Next.js App Router dentro de `app/` (React e JavaScript).
- Ao adicionar ou alterar comandos, testes, banco de dados, variáveis de ambiente ou convenções arquiteturais, atualizar este `AGENTS.md` mantendo apenas diretrizes duráveis e úteis para todas as sessões.
